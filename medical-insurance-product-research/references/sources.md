# 资料来源与检索策略

## 资料清单（每款产品都要尝试取得）
| 编号 | 类型 | 说明 |
|---|---|---|
| 01 | 条款 | 主险及全部附加险（必选/可选）条款 |
| 02 | 费率表 | 当前销售方案费率表；注意“仅展示当前计划”的销售版与备案全表的区别 |
| 03 | 健康告知 | 逐字问卷；免健告产品登记“无健康告知（非缺文件）”并附依据 |
| 04 | 责任免除/既往症清单 | 责任免除、严重既往症/特定疾病清单、特别约定 |
| 05 | 投保须知/产品说明书 | 投保须知、产品说明书、客户告知书、投保提示书、职业表 |
| 06 | 医院/药品/机构清单 | 私立医院、质子重离子机构、特药清单、外购药械目录、护理机构 |
| 07 | 服务手册/指南 | 健康管理服务手册、理赔/直付/客户服务指南 |
| 08 | 上市报道/宣传 | 发布稿、媒体报道、测评——只作线索与上市时间依据 |

## 去哪找
1. **保险公司官网**：首页底部“公开信息披露”→“互联网保险信息披露/产品基本信息/在售产品”。按备案条款名搜索比按销售名更准。
2. **官方投保页/小程序 H5**：页面底部或“保险条款/投保须知”入口通常挂 PDF 附件；用 `discover` 抓取页面中的附件链接（含页面脚本里的 PDF 地址）。页面为前端渲染时，请用浏览器工具打开后保存 HTML 再 `discover <本地html> --base-url <原网址>`。
3. **持牌中介销售页**（慧择、开心保、小雨伞、蚂蚁保等）：常附完整条款/费率/须知 PDF，可作 A 级来源；但要核对版本（计划、年份、条款编号）。
4. **中国保险行业协会**：
   - 人身险公司（寿险、健康险公司）产品：人身保险产品信息库 https://rsxcpk.iachina.cn/（滑块验证，适合人工核对备案名称、条款、费率、销售状态）
   - 财产险公司（财险公司经营的短期健康险）产品：财产保险公司自主注册产品查询 https://cxcx.iachina.cn/（需登录）；国家金融监督管理总局官网“在线服务—财产险公司备案产品目录查询”
5. **上市时间**：官网新闻稿/发布会稿 > 权威媒体 > 测评。无法确定首发日时写“最迟YYYY-MM-DD已上线（依据）”。
6. **用户本地资料**：`import` 整个目录；若目录里有既有“00_来源索引*.json”或“00_*说明.txt”，脚本会恢复文件对应的原始链接。

## 检索词策略
- `medins.py queries` 会生成：产品名 + 资料类型词、`site:<官网域名>`、备案条款名精确匹配、公开信息披露入口、上市与版本线索。
- 同时用销售名与备案条款名检索；版本年份写全（“2026版”“2027”）；系列名 + 计划名（“全家保 易保版”）。
- 找到一份条款后，用条款首页的条款名与编号反查费率表、说明书。
- 免健告/简易健告产品的健告与严重既往症清单常在投保页弹窗或“投保须知”里。

## 证据等级（自动建议，可用 --evidence-level 覆盖）
| 等级 | 含义 |
|---|---|
| A | 保险公司/持牌中介/行业协会正式信息披露原件（条款、费率表、投保须知、清单等） |
| B | 官方域名页面（销售页、发布稿、官方问答），非正式合同文件或未逐项复核 |
| C | 第三方渠道、媒体、测评 |
| D | 无链接线索（截图、口述、公众号标题等）；研究者摘录文本默认 D |

## 常见障碍
- **动态页面/需登录**：用浏览器工具逐字抄录或截图，保存后 `import`，并在 note 注明“动态投保页核验”。
- **SSL 证书错误**：确认是官方站点后 `fetch --insecure`。
- **返回 HTML 而非 PDF**：脚本会识别并按 .html 归档；通常是预览页，需要在页面里找真实下载地址（`discover`）。
- **扫描件**：文本极少会被标记为扫描件，引文核验不可用；需 OCR 或人工逐字核对，字段状态最多标“推定”。
- **验证码/反爬**：不要绕过；改为请用户手工下载后 `import`。
