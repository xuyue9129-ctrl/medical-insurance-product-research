# 字段口径与详细程度

字段定义的机器可读版本在 `assets/schema/fields.json`（`medins.py fields` 可列出）。本文说明**写到什么程度**。

## 总原则
- 每格写到“不用再翻条款也能直接比较”的程度：**数值 + 适用责任 + 条件 + 例外**。
- 分计划/分责任时用“；”分隔，计划差异写全（“计划一/二/三/四：50%/70%/80%/100%”）。
- 组合产品（主险 + 必选/可选附加险）逐项标明“主险/附加险”，保费分列。
- 只能取得部分信息时，写已核实部分，并在同一字段或 `data_gaps` 写缺口；不要用“同系列惯例”补齐。
- 判断类结论（定位、是否放宽）用“推定”并写依据。

## 分组与要点

### 基本信息
| 字段 | 要点 | 示例 |
|---|---|---|
| 公司名称 / 承保公司全称 | 简称用于展示，全称以条款首页为准 | 太保健康 / 太平洋健康保险股份有限公司 |
| 产品名称（销售名） | 官方投保页名称；备案条款名另填 | 蓝医保·免健告百万医疗险（2027） |
| 备案条款名称 | 主险、附加险逐一列；注明必选/可选 | 主险：太保互联网个人一年期住院H款医疗保险；必选附加：…特定药品费用C款医疗保险 |
| 条款编号/备案号 | 条款首页/末页的编号或注册号 | 太平洋健康险[2026]医疗保险057号 |
| 产品类型 | 百万/中高端/长期/住院/专项；一年期或长期；组合形态 | 百万医疗险·一年期·免健告；主险+附加险组合 |
| 适用人群定位（次标体/健康体） | 面向哪类人群：次标体（带病或体检异常，常见免健告/简易健告/易核）、健康体（标准健告）、专项带病体（已确诊专病）、普惠；写依据 | 次标体：免健告准入，严重既往症除外、一般既往症可赔 |
| 上市时间 | YYYY-MM + 依据；只能证明“最迟某日已上线”就这么写 | 2026-10（最迟10月26日已上线；首发日未披露） |
| 销售渠道 | 自营/经代平台/个险代理人/银保；列平台名 | 太平洋健康险自营平台；云保、明亚、大童等 |

### 投保与核保准入
- **健告类型**：免健告 / 简易健告（N条）/ 标准健告 / 专病健告 / 易核 / 智能核保 / 人工核保。不同渠道或活动期版本不同要分开写（如“常规3问；2026-05-28至06-30 限时1问”）。
- **健康告知原文**：尽量逐字；集合式问询照原样分（一）（二），注释（如“高危结节”“高血压伴并发症”的释义）一并抄录。只拿到官方问答或截图时写明“动态投保页核验说明（非逐字原件）”。
- **健告疾病问询范围**：按疾病大类列出问到哪些病、阈值到哪一级（CKD3期还是4期、结节4级还是8mm），并写明与严重既往症清单是否一致——问询范围≠除外范围。
- **住院/手术/检查异常问项（含时限）**：时限（过去2年/5年/6个月）、阈值（累计住院超过10天）、检查项目清单；版本对比时这类时限与阈值的变化最关键。
- **可正常投保的情形**：健告页列明的豁免情形，以及官方问答的命中/不命中示例（例：“2型糖尿病无并发症且2年内累计住院≤10天不命中”）。
- **告知效力与问询外疾病处理**：未如实告知的后果（解除合同/拒赔/退费）、问询外既往症是否可赔（如“只有健告问询所列疾病才算既往症”）、免健告不设告知时既往症如何认定。
- 健告题数减少不等于准入放宽：要看删掉的问项原本是否触发拒保，以及是否同时扩大了疾病问询或除外范围。
- **结节、三高**：分**投保端**（能否投、问到哪一级）与**理赔端**（是否列入严重既往症、阈值、已切除例外）。阈值写全：甲状腺 TI-RADS、乳腺 BI-RADS、肺结节 Lung-RADS 或直径（≥6mm / ≥8mm / >8mm 要区分）、高血压/糖尿病并发症项数。
- **核保辅助与风险筛查**：医保数据授权、体检、AI 评估、风险等级因子——写清它影响“能否投保”还是只影响价格/保障。

### 续保机制
- **保险期间**与**保证续保**分开填：“1年；不保证续保”，“1年；保证续保5年”，“A款保险期间3年、不保证续保”。
- **续保/重新投保规则**：最高年龄、是否审核、费率是否可调、停售后安排、理赔后能否续、续保是否免等待期。
- **等待期**：一般疾病、既往症/特定病种（如一般既往症90日）、意外免等待；等待期内确诊的后果（“后续费用不赔”或“退费终止”）。

### 既往症与赔付规则
- **一般既往症**：可赔/除外/限额/首年比例（“计划一首年按约定比例×50%，计划二不减赔”）。
- **严重既往症**：清单类别（肿瘤、肝肾、心脑血管及糖脂代谢、肺部、自身免疫、其他）、关键阈值、清单出处（条款释义/特别约定/投保须知/单独附件），与上一版是否逐字相同。
- **既往症：特殊可赔／不赔**（总览一句话）：只写与市场常规不同的安排，如“连续投保第3年起旧病限赔1万元，此后每年+5000元”“高危结节3万免赔、30%、年限1万”。
- **免赔额 / 赔付比例**：医保内外分别或共用、家庭共享、无理赔递减、分段比例（“0免赔；2万元以内60%，超出100%”）、指定病种首年比例。
- **未经社保结算**：常见“×60%”，写例外（质子重离子、特需无法结算等）。
- **医院范围**：二级及以上公立普通部 / 特需 / 国际部 / VIP / 私立清单（家数）/ 指定机构。

### 核心额度与特殊责任
- 年度总限额与保证续保期累计限额；一般医疗、重疾医疗是否独立及是否“不可兼得”。
- 康复：额度、病种/手术触发、时间窗（出院后N天）、机构、免赔与比例。
- 门急诊：普通门急诊、互联网门诊、可选门诊责任；没有就写“未设”。
- 外购药械/特药：额度、清单种数、CAR-T 数、临床急需进口药、处方与药房要求。
- 先进疗法：质子重离子（机构限制）、硼中子、光免疫、电场治疗。

### 保费
- **50岁男性保费**：默认 46–50 岁档、有社保、首次投保、年交、含等待期；多计划、多免赔逐一列；组合产品“主险542＋特药102＝644”。
- **保费口径**：年龄档、社保、首年/续保、计划、免赔、是否含附加险、费率表版本或适用日期、性别是否区分。
- 费率表用 `rates import` 搬运，不手抄。

## 易错点清单
1. 把条款编号年份或附件配置时间当作上市时间。
2. 把“2027版”理解为2027年上市。
3. 把题数减少直接写成“准入放宽”——要看删掉的问项原本是否触发拒保，以及是否同时扩大了疾病问询或除外范围。
4. 把保证续保写进保险期间，或把附加险的不保证续保混同主险。
5. 用旧版本条款/费率代替新版本（F款≠H款）。
6. 把“可选责任”写成基本责任；把“增值服务”写成保险责任。
7. 50岁保费没写口径，或把月交×12当年交。
