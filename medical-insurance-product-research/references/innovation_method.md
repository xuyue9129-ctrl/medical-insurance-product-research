# 创新点判断方法

`innovate` 产出的是**候选**：对每款产品的标准化字段做特征打标（特征词典 `assets/schema/features.json`），与对照样本比较。对照样本由三部分组成：
1. **本次研究的其他产品**；
2. **同业对照产品**：`register --from-catalog <id> --role peer` 登记，只整理与候选特征相关的字段（`peers` 命令列出），取值同样逐字引文核验；不进入对比表、报告和 PPT；
3. **样本摘要目录**（可选）：`~/.medins-research/catalog.json` 或工作区 `catalog_user.json` 中带 `overview` 的产品，可用 `python tools/build_seed_catalog.py <自有研究总表.xlsx> --private-out ~/.medins-research/catalog.json` 生成（不要提交到仓库）。

## 候选判定
记某特征“有可比字段的对照产品数”为 N（最少需要 5 款）：

| 情形 | 判定 |
|---|---|
| N ≥ 5，无对照产品具备 | 样本内首见 |
| N ≥ 5，具备的 ≤2 款或 ≤10% | 少见差异化 |
| N ≥ 5，其余 | 行业常见/跟进 |
| N < 5，行业先验为“普遍/较常见”（如质子重离子、院外特药、CAR-T、康复、门急诊、私立医院扩展） | 行业常见/跟进（先验） |
| N < 5，小样本中已有 ≥2 款具备 | 行业常见/跟进（小样本） |
| N < 5，其余 | **样本不足·待补对照**：不判断首见/少见 |
| 相对同系列上一版本新出现 | 另标“本系列新增” |

- 行业先验写在 `features.json` 的 `prior`（普遍/较常见/新兴），来自公开产品的一般市场知识；样本充足但判定与先验冲突时（如先验“普遍”却判“首见”），候选会提示“可能是对照样本漏记”。
- 出现“样本不足·待补对照”时，`next` 会进入“补充同业对照”：用 `peers` 查看推荐产品（同类型、不同系列、附官网链接），登记至少补足到 5 款，再按引导归档条款、整理对照字段、重新 `innovate`。确实无法补充时 `peers --skip --reason "<原因>"`，结论边界必须写明样本不足。
- 附：样本内最早采用、同业示例（按上市时间）、提示（仅 C/D 级来源、尚未原文核验、样本不足）。

## 研究者判断：什么算“真正的创新”
满足至少一条，并有 A/B 级原文支撑：
1. **改变了谁能买**：准入方式变化且确实扩大或重新划分了可保人群（例：免健告 + 自愿医保数据筛查折扣，把风险识别从“拒保”转成“定价”）。
2. **改变了赔什么/怎么赔**：既往症、病种、时点、比例、额度的新机制（例：一般既往症首年比例可选；连续投保逐年开放既往症额度；高危结节专项小额度）。
3. **改变了怎么定价/分层**：新的费率因子或与健康行为挂钩的权益（例：健康任务提升赔付比例；风险等级因子）。
4. **把健康体责任引入次标体产品**，且有配套风控（例：康复、门急诊、私立医院在免健告产品中出现）。

不算创新（判为“跟进”或“营销口径”）：
- 行业已普遍具备的责任（质子重离子、院外特药、CAR-T 已较常见时）；候选判定为“行业常见/跟进（先验）”的特征，除非有对照证据推翻，否则不写成创新
- 仅改名、仅调额度但机制不变
- 只在宣传稿出现、条款/须知中找不到的说法
- 题数减少但删掉的问项原本不触发拒保

## 写法（每条创新点）
- **summary**：是什么 + 原文依据（用 `[[pid:字段]]` 引用）
- **risk_logic**：它在风险管理上的作用（筛选/分担/延后/封顶/引导），属设计逻辑推断的要注明
- **boundary（结论边界）**：样本范围（“样本内首见，不代表全市场”；对照不足 5 款时写明“对照样本不足，未判断是否首见”）、尚缺的材料、不能推出的结论（如“不能据此推定后台没有其他风控”“未按销量或赔付加权”“活动版不等于永久规则”）
- **verdict**：真创新 / 差异化 / 跟进 / 营销口径（待核）

## 版本对比解读要点
- 先列确定的变化（条款编号、主险款别、额度、免赔、比例、等待期、清单），再写方向判断。
- 方向判断要说清受益与受限人群：例如免赔由“医保内外各1万”改为“统一1.5万”，仅医保内费用的人门槛提高，内外都有费用的人反而降低。
- 健告与除外要合看：问项减少但除外扩大，不能判为放宽。
- 同品牌并行分支（如一年期与保证续保5年版并存）不要写成替代关系。
