# 创新点判断方法

判断“是否创新”要对照**整个市场**，不能只看手头的几款产品。`innovate` 先用对照样本给出候选，再要求对每个可能的创新点做**全网核验**：

1. **对照样本（起点）**
   - 本次研究的其他产品；
   - **市场样本库**：内置 `assets/catalog/market_features.json`（数十款主流次标体/百万医疗产品的特征有/无标记），以及可选的本机样本摘要目录（`~/.medins-research/catalog.json`）；
   - （可选）**同业对照产品**：`register --from-catalog <id> --role peer` 登记，只整理对照字段，取值逐字引文核验，不进入对比表与报告。
2. **全网核验（必做）**：对候选判定为“样本内首见 / 少见差异化 / 样本不足·待补对照”的特征，用 Agent 自己的联网搜索检索全市场——保险公司官网信息披露、行业协会产品库、持牌中介平台的条款与产品页，不限于内置样本：
   - 找到具备该特征的其他产品：`market add --feature <key> --product "<公司·产品>" --url <链接> --quote "<页面原文>" --launch <YYYY-MM>`。脚本会下载页面（动态页面可用 `--file` 传入浏览器另存的文件），核验原文确实出现在页面中，保存页面副本与 SHA256；
   - 换用至少 2 组关键词仍未找到：`market none --feature <key> --query "<关键词1>" --query "<关键词2>" --note "<查过的来源>"`；
   - 同一特征找到 3 款同类即可停止（已足以判断为跟进）。`market` 会列出待核验特征与建议检索词。
   - 命中必须是**其他产品**的条款、产品页或官方披露；研究对象自己、同一产品的不同渠道页面不算。宣传稿里的“首创/首款”只是线索，不能当作“全网未见”的依据。

## 候选判定
记某特征“有可比字段的对照产品数”为 N（最少 5 款），全网核验命中的产品另计：

| 情形 | 判定 |
|---|---|
| 行业先验为“普遍/较常见”且样本不足（如质子重离子、院外特药、CAR-T、康复、门急诊、私立医院扩展） | 行业常见/跟进（先验） |
| N ≥ 5 且具备的 >2 款、>10% | 行业常见/跟进 |
| 全网核验命中，样本 + 命中合计 ≥3 款 | 行业常见/跟进（全网核验） |
| 全网核验命中，合计 1–2 款 | 少见差异化（全网核验已有 n 款） |
| 样本中未见且全网检索未见 | **全网未见同类**（附检索日期、检索词与来源） |
| 尚未全网核验 | 保留样本判定，并提示“尚未全网核验，只代表对照样本”；`next` 会停在“全网核验创新点”阶段 |
| 相对同系列上一版本新出现 | 另标“本系列新增” |

- 行业先验写在 `features.json` 的 `prior`，来自公开产品的一般市场知识；样本判定与先验冲突时会提示可能是样本漏记。
- 同业示例按上市时间排序；全网命中里有更早上市的产品时，不能写“首创”。
- 市场样本特征表由样本摘要按规则判定，已知会低估“一般既往症可赔”等摘要不单列的特征；全网核验可以纠正。

## 研究者判断：什么算“真正的创新”
满足至少一条，并有 A/B 级原文支撑：
1. **改变了谁能买**：准入方式变化且确实扩大或重新划分了可保人群（例：免健告 + 自愿医保数据筛查折扣，把风险识别从“拒保”转成“定价”）。
2. **改变了赔什么/怎么赔**：既往症、病种、时点、比例、额度的新机制（例：一般既往症首年比例可选；连续投保逐年开放既往症额度；高危结节专项小额度）。
3. **改变了怎么定价/分层**：新的费率因子或与健康行为挂钩的权益（例：健康任务提升赔付比例；风险等级因子）。
4. **把健康体责任引入次标体产品**，且有配套风控（例：康复、门急诊、私立医院在免健告产品中出现）。

不算创新（判为“跟进”或“营销口径”）：
- 行业已普遍具备的责任（质子重离子、院外特药、CAR-T 已较常见时）；候选判定为“行业常见/跟进”（含先验、全网核验）的特征，除非有证据推翻，否则不写成创新
- 仅改名、仅调额度但机制不变
- 只在宣传稿出现、条款/须知中找不到的说法
- 题数减少但删掉的问项原本不触发拒保

## 写法（每条创新点）
- **summary**：是什么 + 原文依据（用 `[[pid:字段]]` 引用）
- **risk_logic**：它在风险管理上的作用（筛选/分担/延后/封顶/引导），属设计逻辑推断的要注明
- **boundary（结论边界）**：核验范围（“截至某日全网检索未见同类，检索词与来源见对比表”；只做了样本对照时写明“未做全网核验”）、尚缺的材料、不能推出的结论（如“不能据此推定后台没有其他风控”“未按销量或赔付加权”“活动版不等于永久规则”）
- **verdict**：真创新 / 差异化 / 跟进 / 营销口径（待核）

## 版本对比解读要点
- 先列确定的变化（条款编号、主险款别、额度、免赔、比例、等待期、清单），再写方向判断。
- 方向判断要说清受益与受限人群：例如免赔由“医保内外各1万”改为“统一1.5万”，仅医保内费用的人门槛提高，内外都有费用的人反而降低。
- 健告与除外要合看：问项减少但除外扩大，不能判为放宽。
- 同品牌并行分支（如一年期与保证续保5年版并存）不要写成替代关系。
